# Learning OS

App mobile-first para **entender e lembrar**. Vault no aparelho (`localStorage`). Três modos: Destilar, Socrático, Comparar.

Pré-carregado: Preface de Iyer (visão, alucinação, ilusão, trance) + 5 cards.

## Adicionar à tela inicial

- **iPhone / iPad (Safari):** Compartilhar → Adicionar à Tela de Início.
- **Android (Chrome):** menu ⋮ → Adicionar à tela inicial / Instalar app.
